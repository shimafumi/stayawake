# stayawake

実行している間、Windows のスリープとディスプレイの消灯を止める小さなツールです。コンソールには現在時刻を 1 秒ごとに表示します。

## 必要なもの

- Windows
- Python 3（Python ランチャー `py` が使えること）。外部ライブラリは不要です。

## 使い方

`stayawake.bat` をダブルクリックします。コマンドから直接起動することもできます。

```
py stayawake.py
```

止めるときは Ctrl+C を押すか、ウィンドウを閉じます。どちらの場合も、スリープの設定は元に戻ります。

## 仕組み

Windows API の `SetThreadExecutionState` を呼び、システムとディスプレイを起こしたままにするよう Windows に伝えています。管理者権限は不要で、OS の電源設定も書き換えません。
